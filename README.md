<h1>Blinkit Dashboard Using PowerBI</h1>

A Power BI dashboard project that analyzes Blinkit’s sales performance, customer satisfaction, and inventory distribution, transforming raw data into interactive insights
🧠 Project Overview

This project delivers an interactive Power BI dashboard built to explore Blinkit’s retail data, focusing on key business metrics and performance indicators that help with operational decision-making. 
GitHub

📊 Key Performance Indicators (KPIs)

The dashboard tracks the following: 
GitHub

Total Sales – Overall revenue generated (~$1.20M)

Average Sales – Mean revenue per sale (~$141)

Number of Items – Total unique items sold (~8,523)

Average Rating – Customer rating average (~3.9/5)

These KPIs are shown as dynamic cards or visuals in Power BI to provide a quick snapshot of business performance
🔍 Dashboard Features & Visuals

The project includes several interactive features and visual breakdowns: 
GitHub

Filter Panel: Enables filtering by outlet location type, outlet size, and item type.

Trend Analysis: Visually tracks outlet establishment growth (e.g., 2012–2022).

Fat Content Analysis: Compares sales of low-fat vs regular products.

Item Type Distribution: Shows sales distribution by product categories.

Outlet Performance Views:

Sales by outlet size and location tier

Comparison of outlet types based on sales, average sales, customer ratings, and item visibility

🧩 Insights & Observations

Key insights derived from the dashboard include: 
GitHub

Strong overall sales performance with total sales exceeding $1M.

Health-conscious buying behavior with preference toward low-fat products.

Fruits, vegetables, and snack foods rank among the top categories sold.

Medium-sized outlets in Tier 3 locations tend to be more profitable.

Supermarkets show higher sales volumes, whereas grocery stores offer better item visibility.
